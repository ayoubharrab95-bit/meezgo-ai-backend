# MoneyForge MVP

Revenue-first micro-agency engine.

## Goal
Do not wait for marketplace bounties. Convert real business problems into small, fixed-price deliverables.

## Pipeline
1. collect a real prospect
2. audit measurable conversion problems
3. score commercial urgency
4. generate one fixed-price offer
5. prepare personalized outreach
6. close and deliver
7. convert the client to recurring maintenance

## First offer
**Conversion Rescue** — focused mobile/CTA/order-path improvement.

Price ladder: $10 / $19 / $29 / $49.

The MVP deliberately does not auto-send messages. Outreach must use a connected communication channel and respect that channel's rules.

## Expansion gates
- Gate 1: first paid transaction
- Gate 2: three paid transactions
- Gate 3: $100 cumulative revenue
- Gate 4: recurring maintenance client
- Gate 5: automate qualified prospecting and follow-up

Never expand automation before the previous gate has evidence.
